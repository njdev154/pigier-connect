# Pigier Connect

Site vitrine et portail de préinscription pour **Pigier Yopougon**, réalisé en HTML, CSS et JavaScript.

## Ce que fait le site

- Présente l'école et ses filières (BTS / Licence)
- Met en avant les meilleurs élèves, les événements et les résultats
- Filtre de recherche pour trouver rapidement une formation
- FAQ déroulante pour répondre aux questions fréquentes
- Localisation de l'école sur Google Maps
- Formulaire de préinscription avec confirmation à l'écran

## Technologies

- HTML5 / CSS3 (Flexbox, `clamp()` pour le responsive)
- JavaScript simple (menu mobile, FAQ, recherche, formulaire) — un seul fichier `script.js`
- Polices Google Fonts : Poppins (titres) et Lato (texte)

## Structure

```
index.html     → Page unique du site
styles.css      → Feuille de style
script.js       → Interactions (menu, FAQ, recherche, formulaire)
logo2.png       → Logo de l'école
photo(2).png    → Photo utilisée sur la page
video/          → Vidéos de présentation
```

## À faire avant mise en ligne définitive

- Remplacer les statistiques (92%, 87%, 1200+, 35+) par les vrais chiffres de l'école
- Connecter le formulaire à un vrai service d'envoi (ex : Formspree) pour recevoir les préinscriptions par e-mail
